# OTIF Tracker

**This dashboard shows how companies montior delivery performance, inventory ineffeciences and customer service quality using PowerBI**

**1. Business Problem**
-> Inventory shortages, Transport ineffeciences and declining On-Time In-Full (OTIF) delivery rates were driving up expedited freight cost and negatively impacting customer satisfaction.

**2. Key Insights**
-> 60% orders were delivered On-Time and In-Full
-> West region recorded lowest OTIF rate across all regions
-> The monthly OTIF performance showed significant fluctuations, peaking in Feb 25 before dropping in March
-> Truck transport contributes to highest delays
-> Fulfillment consistently fell short across all months with total delivered quantity never achieving 100% fill rate

**3. Strategic Recommendations**
-> Improve warehouse stock planning
-> Optimize transport routing (specially for trucks)
-> Focus on low performing regions
-> Improve supplier coordination
